# BrainTumor-Agent 演示指南

## 演示数据边界

| 数据 | 用途 | 是否可用于Dice |
| --- | --- | --- |
| `case-031412bee7e3491c` | 本地去标识化公开病例、完整界面演示 | 否 |
| UPENN-GBM 10例队列 | 独立机构五折GPU验证 | 是 |
| `BT-Demo-001/002` | 程序合成的上传、Mask和前端联调 | 否 |

不要把合成数据或无真值病例写成独立模型验证结果。

## 启动

在项目根目录打开两个PowerShell终端：

```powershell
.\scripts\start_backend.ps1
```

```powershell
.\scripts\start_frontend.ps1
```

浏览器访问以下固定病例地址，无需重新上传或运行CPU推理：

`http://127.0.0.1:5173/?case=case-031412bee7e3491c#workbench`

演示前运行：

```powershell
.\scripts\validate_demo.ps1
```

## 即时演示病例

本机准备好的病例为`case-031412bee7e3491c`，已有四模态、BraTS标准Mask、
`features.json`和与当前指标一致的辅助报告。前端优先读取URL中的`case`参数，随后将
病例保存到浏览器本地存储。面试演示使用上述固定地址，避免等待CPU重新推理。

## 五分钟演示顺序

1. 展示T1、T1ce、T2、FLAIR四窗口和切片联动。
2. 切换WT、TC、ET图层，说明颜色为WT青、TC橙、ET紫。
3. 展示总体积、核心体积、增强体积、水肿体积和最大径。
4. 点击“生成辅助报告”进入医学助手，展示医生指令“生成简洁的会诊版报告”的
   确认式修改流程。
5. 询问“成人弥漫性胶质瘤随访时MRI需要关注哪些变化？”，展示EANO页码引用。
6. 最后展示UPENN-GBM 10例五折GPU验证：WT 0.895287、TC 0.918673、ET 0.862139。

## 演示口径

- 项目用于科研和教学，不作为独立诊断依据。
- 当前本机使用CPU单折进行新病例演示；公开精度来自已完成的五折GPU验证。
- UPENN结果仅有10例，不能据此宣称模型具有临床级泛化能力。
- Qwen或网络不可用时，仍可展示已有报告、分割、定量数据和本地RAG索引。
